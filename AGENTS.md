# AGENTS.md

## Project overview
This repository documents ethical considerations related to the use of disabled customer data. The project is primarily documentation-focused and centers on research, analysis, policy discussion, and clear explanations of responsible data practices.

https://github.com/Double-FW/Data_Ethics_and_Disability

## Repository conventions
- Prefer Markdown for documentation updates and discussion content.
- Keep the README and other top-level documentation aligned with the repository's purpose.
- Use clear headings, concise paragraphs, and structured lists for readability.
- When adding research, policy references, or external claims, cite sources or include a clear attribution.
- Maintain a respectful, evidence-based tone when discussing disability, ethics, and data use.
- Preserve existing document structure and naming patterns unless a broader reorganization is clearly needed.

## Content guidelines
- Focus on ethical analysis, risks, and safeguards in data collection, processing, and use.
- Highlight inclusion, accessibility, consent, bias, privacy, and accountability considerations where relevant.
- Avoid unsupported claims or speculation; prefer well-scoped, source-backed statements.
- If a change affects project scope, update the README or related docs so the repository remains easy to navigate.

## Editing expectations
- Keep changes small, obvious, and easy to review.
- Prefer incremental documentation improvements over broad rewrites.
- When introducing a new topic or document, add a short summary or link from the most relevant existing file.
- Ensure formatting remains consistent and Markdown renders cleanly.

## Validation
This repository does not appear to include a formal test suite. For validation, check that:
- Markdown formatting is valid and readable.
- Links are correct and files are in the expected location.
- Documentation remains consistent with the repository's ethical focus and purpose.
